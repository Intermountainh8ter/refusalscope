# refusalscope

A research harness for one question:

> Does removing the refusal direction from an LLM (abliteration, for example with the
> open-source Heretic tool) damage structured tool calling, and does it make the model more
> likely to follow instructions injected into tool results?

**Results: NOT YET RUN.** No real model has been evaluated with this repository. There are no
numbers here, and none will appear until result files produced by real runs exist in
`results/`. The hypotheses, metrics, sample sizes and decision rules were written down before
any analysis code, in [docs/PREREGISTRATION.md](docs/PREREGISTRATION.md). The measurement
design is in [docs/METHODOLOGY.md](docs/METHODOLOGY.md).

Status: under construction. The full README (quick start, serving commands for Windows and
Linux, results table) is added in the last build phase.
